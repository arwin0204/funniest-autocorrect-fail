A single-line autocorrect fail for make.fun's "Funniest Autocorrect Fail" bounty: an ordinary back-to-school reminder from one parent to another, wrecked by one letter — "public" comes out as "pubic". The program writes the line to `/output/entry.txt`, deterministically, using only the Python standard library.

## Run it

```sh
python3 main.py
```
